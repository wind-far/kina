# 智能画布本地参考页规格

## 目标与边界

- 路由：`/canvas?returnTo=/agentic-assets-canvas&projectId=<id>`。
- 视觉基线：白色顶栏、浅灰无限画布、左侧工具条、左下缩放器、底部创作输入栏和右侧对话抽屉。
- 页面实现完整的本地编辑逻辑与浏览器端持久化；不伪造 AI 生成、账号/会员、支付、云端保存或对外分享服务。
- `returnTo` 仅接受站内绝对路径；非法值回退到浏览器历史或首页。

## 本地画布能力

- 画布支持空白区或空格拖拽平移、滚轮缩放、缩放按钮、双击缩放数字恢复 100%。缩放范围为 10%–200%。
- 支持图片、画板和文字三类节点；可选择、拖拽、方向键移动、复制、删除，文字可双击编辑并用 `Ctrl/Command + Enter` 保存。
- 图片支持本地选择、浏览器端压缩为 WebP、加入画布、失败占位、裁剪缩放和水平/垂直偏移；单张限制为 12MB，不上传到服务端。
- 项目菜单提供本地 JSON 导入/导出、清空画布、恢复初始示例和恢复视图；破坏性操作需要在页面内二次确认。
- `A` 新建画板、`T` 新建文字、`Ctrl/Command + D` 复制、`Delete` 删除、`Ctrl/Command + 0` 恢复视图、`?` 打开帮助。

## 输入与对话

- 底部输入支持焦点动效、Enter 发送和 Esc 收起。发送内容成为本地对话记录。
- 右侧对话抽屉支持上传本地参考图附件、文本消息、Agent 模式/内容类型选择和两个本地开关；Enter 发送，Shift+Enter 换行，Esc 关闭。
- 所有“Agent”反馈都会明确说明当前未连接 AI 生成服务。
- 分享按钮只复制当前本地 URL；积分和会员入口只展示边界说明，不会虚构账户或支付状态。

## 持久化与资源

- 每个 `projectId` 使用独立 `localStorage` 键保存标题、画布节点、视图、对话、开关、主题和草稿；存储异常时降级为本次会话并提示。
- 默认海报位于已忽略的 `public/local-canvas-assets/ai-editorial-poster.webp`；QA 截图也位于 Git 忽略路径，均不会进入仓库。
- 图片不存在或解码失败时显示内置占位态；不请求外部字体或素材服务。
- `/canvas` 跳过系统安装、账号和公共配置初始化；该白名单仅作用于本地参考路由。

## 响应式验收

- 桌面基线：2048 × 1001 和 1260 × 662。
- 移动端：390 × 844；工具条、输入栏和缩放控件适配，抽屉覆盖画布。
- 页面不得出现横向滚动条；控制台不得出现运行时错误。

## 回归命令

- 纯状态逻辑：`pnpm exec tsx scripts/tests/test-canvas-reference-state.mjs`
- 画布功能声明：`pnpm exec tsx scripts/tests/test-canvas-workspace-features.mjs`
- 全部本地脚本：`pnpm test:scripts`
- 类型检查：`pnpm type-check`
- 生产构建：`pnpm build`
