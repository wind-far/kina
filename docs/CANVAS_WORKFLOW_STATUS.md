# 无限画布与工作流功能状态

更新时间：2026-08-07

## 已完成

### 无限画布

- 图片拖入、批量本地上传和资产库选取。
- 上传文件写入 `AssetItem`，画布不再依赖模拟图片生成。
- 画布项目创建、打开、重命名、删除和自动保存。
- 图片可在任意自由坐标拖拽和四角等比缩放，移动与缩放支持撤销/重做。
- 图片自由坐标、层级、尺寸与视口快照持久化，刷新或切换项目后可恢复。
- 快照已升级到 schema v2；旧版网格快照会在读取时无损迁移为自由坐标。
- 自动保存携带版本 ID 与更新时间；旧标签页保存过期内容时返回 409 冲突，不再静默覆盖新内容。
- AI 生成结果可直接加入画布。
- 支持导出完整项目 JSON，或只导出当前选区（节点、选区内部连线和既有资源引用）；选区导出不会携带项目级助手会话。

无限画布项目复用 `WorkflowDefinition` / `WorkflowDefinitionVersion` 存储，场景为 `INFINITE_CANVAS`，与可视化工作流数据相互隔离。

### 可视化工作流

- 节点拖拽、缩放和平移、连线、小地图、复制粘贴。
- 连线时校验端点、自连接、重复连接和循环依赖。
- 撤销/重做；一次模板插入只形成一个历史操作。
- 工作流列表、自动保存和版本快照。
- 历史版本回滚：回滚会创建一个新的草稿版本，不覆盖既有历史。
- 整图运行：运行前校验图结构，由服务端按拓扑依赖顺序串行执行 `llmConfig`、`imageConfig`、`videoConfig`。
- 页面关闭不会停止已经提交的服务端工作流；重新打开后会继续轮询运行记录并回填文本、图片或视频结果。
- 运行中可停止：立即终止后续节点调度，并请求停止当前 LLM、图片或视频生成任务。
- 失败或服务重启中断的运行支持“从失败节点重试”，已经完成的节点不会重复计费执行。
- LLM 输出可作为图片或视频提示词；图片和视频生成会复用模板中已有的结果节点。
- 每次整图运行会创建服务端 `WorkflowRun`，每个可执行节点对应一条 `WorkflowNodeRun`。
- 节点开始、完成、失败、停止及整图完成状态会持续落库，并关联可用的 `GenerationRecord`。
- 重新打开工作流后可在“运行记录”查看上次运行状态、节点结果、错误信息和生成链接。
- 节点选中后会向画布助手提供“当前节点 + 递归上游节点”上下文；普通对话不会自动携带图片，只有图片生成模式才会加入画布图片引用。
- 图片节点已提供全景、情绪、宫格切分、角度、打光、裁剪、下载、预览及“加入 Agent”工具；AI 变换会先创建下游结果节点并预填提示词，不会在点击工具时直接消耗额度。
- 文本节点已提供 Markdown 格式工具、自动排版、表格插入、全屏编辑、文档导入及图片反推提示词。
- 图片可以标记为“主体”，主体标记随工作流版本保存，并自动加入图片或视频生成参考；支持取消标记。
- 新增导演台和音频节点。两者支持新增、连线、编辑、复制、删除及自动保存；导演台用于保存镜头规划，音频节点用于上传和播放素材。
- 工作流底部输入栏支持图片/视频模式切换、模型与尺寸参数、最多 4 个引用、主体创建和站内灵感。

## 运行前置条件

整图运行依赖后台已经配置并启用对应的厂商与模型：

- `llmConfig`：至少一个可用对话模型。
- `imageConfig`：至少一个可用图片模型。
- `videoConfig`：至少一个可用视频模型，以及兼容“创建任务 + 按任务 ID 查询结果”的视频接口。
- 图片反推提示词依赖支持图片理解的对话模型；模型不具备视觉能力时会返回厂商错误。

未配置 API 密钥、模型或对象存储时，画布编辑、保存和版本管理仍可使用，但真实 AI 生成会返回明确错误。

## 当前边界

- 当前服务端调度器由单个 Node 服务进程承载，不是 Redis/BullMQ 等独立分布式队列；页面关闭不影响运行。服务重启时，启动恢复器会将没有 Redis 执行锁的遗留生成任务标记为“服务重启导致任务中断，可重试”；仍被其他实例持锁的任务不会被误判为失败。原始请求不会被自动重放，需手动点击重试。
- 服务端视频任务使用 FormData 创建上游任务并在后台轮询；视频结果写入 `GenerationRecord`、`GenerationOutput` 和视频资产项。
- 导演台和音频节点当前属于规划/素材节点，不会被服务端整图执行器调度；节点内会明确显示这一状态。
- 发生自动保存冲突后会保留当前页面内容并提示重新打开；当前尚未提供自动合并两个版本的能力。
- 视频厂商没有统一的远端取消协议；停止工作流会中止本地请求与轮询，但已经提交给第三方的视频任务可能继续在远端运行。
- 输出节点保存的是结果 URL；外部 URL 的长期有效性取决于实际存储配置。
- 宫格切分保证画布节点与连线的原子提交；底层通用上传接口当前没有文件删除能力，上传成功后其他分片失败时可能留下未被画布引用的存储文件，需要由存储生命周期策略清理。
- 版本回滚只恢复画布定义与运行配置，不撤销已经产生的上游计费或远端生成任务。

## 本地验收

```bash
pnpm prisma:migrate:deploy:local
pnpm prisma:generate
pnpm type-check
pnpm test:scripts
pnpm exec tsx --env-file=.env.development scripts/tests/test-workflow-runs-integration.mjs
pnpm build
```

GitHub Actions 的 `代码质量` 工作流会在 `main` 推送和 Pull Request 时重复执行类型检查、脚本测试及生产构建。Docker 发布和自动部署分别受仓库变量 `DOCKER_PUBLISH_ENABLED=true`、`DOCKER_DEPLOY_ENABLED=true` 控制；未配置开关和所需 Secrets 时不会自动发布或部署。

页面验收建议：

1. 在无限画布新建项目，上传两张图片，将图片拖到非网格位置并从左上角缩放；测试撤销/重做后刷新页面，确认自由坐标、尺寸和视口恢复。
2. 插入“文生图基础”模板，确认一次撤销可以完整移除该模板，一次重做可以恢复。
3. 尝试自连接、重复连线和造成循环的连线，确认操作被拒绝并显示原因。
4. 配置可用模型后点击“运行工作流”，关闭页面再重新打开，确认文本、图片、视频节点继续按依赖顺序执行并复用已有结果节点。
5. 打开工作流历史版本并回滚，确认系统新增一个草稿版本，原历史版本仍保留。
6. 选择有图的图片节点，依次检查角度/打光预设会创建下游节点并预填提示词；使用撤销恢复原图结构。
7. 新增导演台和音频节点并填写内容，等待自动保存后刷新，确认字段和连线恢复；两类节点不应进入整图执行队列。
8. 将图片标记为主体，确认图片与视频输入栏自动引用；刷新后标记仍存在，取消主体后引用恢复。
9. 宫格切分时模拟某个分片上传或连线失败，确认画布不会留下半套结果节点；上传非法格式、空文件和超过 100MB 的音频应在客户端被拒绝。
10. 运行包含视频节点的工作流，确认创建任务、后台轮询、视频输出入库、停止和失败重试均在运行记录中可追踪。
