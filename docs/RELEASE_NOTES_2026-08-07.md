以下项目不是代码回归失败，而是当前本地与 GitHub 环境缺少必要配置：

1. 本地数据库没有启用的正式模型、兼容模型或 API 密钥，因此尚未执行对话、图片反推、图片变换和视频各一次的真实付费调用。

3. Chrome 浏览器安全策略拒绝对 `127.0.0.1` 页面执行截图和元素级视觉读取；已确认页面可加载、登录态有效且结构可读，但桌面/移动端截图级像素回归仍需人工在已保留的本地标签页完成。

## 启用发布所需配置

- 镜像发布：设置 `DOCKER_PUBLISH_ENABLED=true`，并配置 `DOCKERHUB_USERNAME`、`DOCKERHUB_TOKEN`；可选设置 `DOCKER_IMAGE_NAME`。
- 自动部署：设置 `DOCKER_DEPLOY_ENABLED=true`，并配置部署工作流引用的 SSH 与服务器环境 Secrets。
- 真实模型验收：在管理端启用至少一个对话模型、一个支持图片理解的对话模型、一个图片模型和一个视频模型，并确认相应 API 密钥与计费额度有效。
